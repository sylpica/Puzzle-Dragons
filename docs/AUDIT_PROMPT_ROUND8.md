# パズドラ練習アプリ品質監査（ラウンド8）のお願い

あなたは品質監査の専門家です。添付の `index.html`（パズル＆ドラゴンズの盤面練習用・単一ファイルWebアプリ）を監査してください。

## 成果物の形式（厳守）
- 報告書と証跡は、必ず**生成ファイル**として出力してください（ファイル名に `ROUND8` を含めること。例: `ROUND8_AUDIT_REPORT.md`、`ROUND8_EVIDENCE.json`）。チャット本文への長文転記は不要です。
- 報告書の冒頭に、対象ファイルの行数と、本指示書の検証項目見出し（W1〜W5）を復唱してください。
- 各指摘には必ず「再現手順」「実在するコード箇所（関数名・行の内容）」「実測値」を付けてください。実在しない関数名・要素IDを根拠にした指摘、実測していない数値は無効です。
- 問題がなかった項目は、試行規模（回数・盤面数など）を添えて「実測のうえ問題なし」と書いてください。
- 検証できなかった項目は「未検証（理由）」と明記してください。推測で補わないでください。
- 修正提案は、実在する関数に対する差分形式（変更前／変更後のコード断片）でのみ提示してください。
- 要約表と詳細で数値を食い違わせないでください（過去ラウンドで発生したため）。

## 意図的な仕様（欠陥として扱わないこと）
- コンボは1コンボずつ順に発生する（同時判定しない）。演出は1コンボあたり約250ms。
- 落ちコンなしが基本: 消去で空いたマスはターン中は空白のまま、新ドロップは落ちてこない。既存ドロップの落としによるコンボは成立する。盤面のコンボ終了時に空マスへ補充し、その補充ではコンボは成立しない。
- 操作時間の初期値は6.0秒（本家の現行仕様）。
- ルーレットは全マス共通のグローバルクロックで同期し、操作中も回り続ける（掴んでいるマスとロックされたドロップは凍結）。解決中は位相をラッチする。表示の更新は約100ms間隔のポーリングで追従するため、位相切替直後に最大で約100msの表示遅延がありうるのは設計の範囲。全マスが同じルーレットの盤面ではシャッフル後もマッチが残りうる（仕様メモに明記済み）。
- ロック解除はL字消しの簡略ルール。3個以上繋がった爆弾は他の爆弾の爆発に巻き込まれない。
- 目覚め「多め」の出現率は実測約33%（公称3/8とは異なる）のが正常。
- 特殊目覚め: お邪魔・毒・猛毒は補充プールに重み付きで混ざる（単独ONで約25%）、トゲは補充ドロップの15%に付く、超暗闇は補充ドロップの約30%に**残り1ターン**で付く（本家の「一部だけ・残り1ターンで落ちてくる」挙動に合わせた仕様）。落下率は本家非公表のため割合はアプリの練習用設定。
- 「のみ」では選んだ2〜4色以外のドロップは落ちてこない（落ちコンなし補充でも純度が保たれるのが仕様）。
- 消せないは属性単位で選ぶ仕様。属性判定は現在の実効タイプ（ルーレット表示色を含む）に対して行う。消せない属性の選択は、盤面リセットや盤面サイズ変更では保持され、全リセットと全状態クリアでのみ初期化されるのが仕様。
- ドラッグ中、掴んだドロップは指が盤面の外に出ても盤面の内側に収まるようクランプされるのが仕様（入れ替え判定はマス単位）。
- 保存機能は廃止済み（存在しないのが正常）。ページズームは全面禁止が仕様。
- パーティ・敵・HPゲージ・勝敗判定は未実装が仕様（ダメージは最大HP比%表示のみ）。

## 検証項目

### W1 バッチ3の本家寄せ変更の再検証
- 超暗闇目覚めON時の補充を大量測定し、超暗闇の付与率が約30%であること、付いた超暗闇のカウントがすべて1であること、ターン経過で1→0に減って表示が戻ること。
- 「のみ」（2色・3色・4色）×落ちコンなしで、負荷の高い盤面（広範囲を空にした盤面、既存ドロップが偏った盤面）でも補充が純度を保ち、かつ補充後にマッチが残らないこと。試行規模を明記すること。
- ドラッグのクランプ: 実ポインター操作で四辺・四隅の外側までドラッグし、掴んだドロップが盤面外に出ないこと。クランプされた状態からの指離しで手が正常に解決すること。クランプ中も隣接マスへの入れ替えが正しく行われること。

### W2 ラウンド7修正の再検証
- 消せない属性: 盤面リセット・盤面サイズ変更で保持され、全リセット・全状態クリアで初期化されること（各操作を実測）。
- 消せない属性チップの変更後に「元に戻す」を押しても、属性設定が巻き戻らないこと（履歴が無効化されていること）。逆に、ドラッグで作った履歴は属性変更を挟まなければ通常どおり使えること。
- 「のみ」の内部集合を空にする等のプログラム的異常状態でも、補充・シャッフルが例外なく動作すること（防御の確認。通常UIで到達不能なことは承知のうえで、落ちないことだけ確認）。
- 全リセット後のルーレット・カスタム色が、初回起動時と同じ基本6色のみチェックの状態に戻ること。
- 幅280px（および300px）でヘッダー・ステータス・文書に横はみ出しがないこと。

### W3 アンドゥ履歴の整合性（全コントロール列挙）
スナップショットに含まれる状態（盤面・位置ギミック・ターン・最大コンボ・被ダメ・消せない属性）を変更しうるUI操作をすべて列挙し、それぞれについて「履歴が正しく無効化される／保持される」を実測してください。少なくとも次を含めること: ペイント（変化あり／変化なし）、一括変更・陣（成功／検証失敗）、全状態クリア、消せない属性チップ、「のみ」色チェック、特殊目覚めチップ、目覚めセレクト、落ちコンセレクト、操作時間の変更、ルーレット設定の変更、盤面サイズ変更、シャッフル、盤面リセット、記録リセット、被ダメリセット、全リセット、編集モードの開閉（編集なし／編集あり）、動かさないタップ、ドラッグ中のモード切替。
- 保持されるべき場面で保持され、無効化されるべき場面で無効化されるかを判定し、食い違いを指摘してください。

### W4 新機能を全部ONにした長時間ファズ
消せない属性（2属性）＋「のみ」（3色）＋特殊目覚め全ON＋ルーレット混在盤面＋落ちコンなし/ありの両方で、ランダム操作列（ドラッグ・編集・各種リセット・アンドゥ・シャッフル・サイズ変更）を長時間実行し、例外・状態不整合（空マス残り、未定義タイプ、表示と内部状態の乖離）がないことを確認してください。被ダメ計算のスポットチェック（毒・猛毒・爆弾・トゲの式）も含めてください。

### W5 仕様メモ（フッター）の主張と実測の突合
画面下部の「仕様メモ」の各文を取り上げ、主張ごとに実測またはコード照合で真偽を確認してください。食い違う文があれば、該当文と実測結果を対にして指摘してください（文面の修正案も添えること）。

## 重点の置き方
ラウンド7までの指摘は検証・修正済みです。本ラウンドは、直近の変更（バッチ3とラウンド7修正）の正しさと、アンドゥ履歴の整合性、仕様メモの正確さに集中してください。過去に不採用となった観測（位相切替の表示遅延など、意図的な仕様に明記したもの）を再指摘しないでください。
