あなたは熟練のQAエンジニアです。添付の単一HTMLファイル（パズドラ風パズル練習アプリ）を、実際にブラウザで動かして監査してください。本ラウンドの目的はただ1つ、これまでの全修正が正しく入り、**新規の不整合が残っていないことを確認して収束を判定する**ことです。新しい探索軸は設けません。前ラウンドまでの仕様解釈を蒸し返さず、下記の確定仕様を前提に検証してください。

## 確定仕様（意図どおりの挙動 — 指摘してはいけないもの）

- 盤面 5×4 / 6×5 / 7×6、初期はシャッフル直後の盤面でギミックなし。操作時間の初期値 6.0秒（1.0〜200.0、0.1刻み）。パーティ・敵・HPゲージ・勝敗判定は未実装が仕様、ダメージ表示は最大HP比%のみ。
- ダメージ：毒はつながり1組ごとに（個数+1)×5%、猛毒（個数+1)×12.5%、爆弾は未マッチで離すと先に爆発し1個20%＋行列破壊、棘は移動でずれたマス数×4%。
- 爆弾の保護：3個以上つながった爆弾は他の爆弾の爆発で破壊されません。解決の順序は「未マッチ爆弾の爆発→落下→コンボ判定」で本家と同じ。落下で繋がりが崩れた場合はコンボになりません（保護はコンボの保証ではありません）。
- コンボは1コンボずつ順に発生。落ちコンなし：消去マスはターン終了まで空白、補充は全コンボ終了後に1回だけ、その補充はコンボしません。落ちコンあり：消去のたびに落下＋補充。
- 非収束フェイルセーフ：落ちコンありで全ルーレットマスの同一マッチが3回連続したら打ち切りターン終了へ。上限99コンボ。**上限に到達して終了する場合、それ自体は仕様どおりの正常終了です**（その際も盤面・表示・状態が整合していることを確認してください。「自然終了の普遍性」は判定対象外です）。
- ルーレット：色の順序は火→水→木→光→闇→回復。全マス同一のグローバル時計、掴んでいるマスとロック中は停止、解決中は位相固定。間隔プリセット 2秒/1秒/0.5秒。特殊ドロップがルーレットマスに入ると火に変換（ロック中を除く）。カスタム色は最低1色。
- ロック解除はL字マッチ時のみ（角マスを含むこと、簡易仕様として明記済み）。
- 超暗闇：目覚めトグル時、約3割のドロップに残り1ターンで付きます。カウントダウンはターン開始時に盤面にあったドロップのみ、そのターンの解決終了時に進みます。
- 目覚め「のみ」は2〜4色のカスタム集合で、落下プールは集合の色のみ（特殊ドロップ目覚めと併用しても混ざりません）。「割合アップ」の実効比率は約33%（仕様メモに明記済み）。
- 消せない属性は属性単位で、盤面リセット・サイズ変更でも保持、全リセットと全状態クリアでのみ解除。
- アンドゥ：最初に実際に交換した時点で履歴が確定。無操作のタップ、実際に変化のない編集（同種・無修飾ドロップの再配置、消すもののない全状態クリア、無変化のペイント等）では履歴は消えません。実変更のある操作では破棄されます。
- 設定のみが端末に保存されます（盤面そのものは保存されません）。保存値の検証は**厳密**です：操作時間は数値型かつ 1.0〜200.0 の範囲内のみ（範囲外は初期値6.0、丸めません）、ルーレット色は有効な色だけを残し（重複除去）1色も残らなければ初期6色、ルーレット間隔は**文字列型**で "500"/"1000"/"2000" の場合のみ（数値型は型違いとして初期値 "1000"）、サイズ・落ちコン・目覚め・プリセット名は許容文字列の場合のみ。型違い・壊れたJSON・未知の値は項目ごとに初期値へ。
- 全リセットには確認ダイアログがあります。ポインターキャンセルでは手は無効になり盤面が復帰してターンは進みません。「元に戻す」ボタンは履歴がない間は無効表示。ルーレットマスがないときは時計による待機中再描画なし。編集のタブとツールはモード往復で保持。
- 盤面表示：縦向きは画面幅いっぱい（最大480px）、横向きは縮小して中央。ページズームは全面禁止。
