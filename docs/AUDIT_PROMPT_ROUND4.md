# パズドラ パズル練習アプリ 総合監査プロンプト（ラウンド4・全要件版）

あなたはモバイルゲームの品質監査の専門家です。対象は単一HTMLファイルの静的Webアプリ「パズドラ パズル練習アプリ」（パズル＆ドラゴンズの盤面操作を練習するための個人用ツール）です。添付の `index.html` 全文と本プロンプトの要件リストを突き合わせ、欠陥・仕様不一致・実機との乖離を網羅的に洗い出してください。

## 最重要方針

- **実機（本家パズル＆ドラゴンズ）にどれだけ近いかが最重要の評価軸です。** 数値・処理順序・タイミング・挙動について、本家の仕様と異なる点はすべて指摘してください。
- ただし「意図的な仕様（後述）」に挙げた項目は欠陥として扱わないでください。それ以外で本家と違う点は、根拠（公式発表・攻略情報の一次/準一次ソース）を示して指摘してください。
- 推測で断定しないこと。本家の仕様で確認できない点は「未確認」と明記してください。
- 指摘には重大度（高/中/低）、根拠（コードの該当箇所または実測手順）、本家との差異かどうか、修正案を含めてください。

## 意図的な仕様（欠陥扱いしないこと）

1. コンボは同時判定ではなく **1コンボずつ順番に** 処理・表示する（利用者指定）。
2. ロック解除は「L字消しで盤面全体のロックが外れる」簡略ルール（画面下部の仕様メモに明記済み）。
3. ルーレットはコンボ解決中は位相を固定（ラッチ）する（練習の再現性優先）。
4. HPゲージは無く、毒・爆弾・トゲの被ダメージは最大HP比の％表示のみ。被ダメ表示はターン毎にリセット。
5. ルーレットマスに入ったお邪魔・毒・爆弾ドロップは火ドロップに変換されてサイクルに加わる。
6. 爆弾が3個以上つながって消える場合、その爆弾は他の爆弾の爆発から保護される（攻略Wiki FAQに基づく実装）。
7. 保存機能（盤面の保存・盤面コード）は利用者の決定で**撤去済み**。存在しないことが正しい状態です。
8. 画面の拡大（ピンチズーム等）は利用者指定で禁止。

## 全要件リスト（すべて監査対象）

### 起動・画面構成
- R1: 開いた瞬間に設定画面ではなく、シャッフル済み盤面で即座にパズル練習ができる。初期状態はギミックなし、操作時間は本家の現行基本値に合わせた **6.0秒**。
- R2: 盤面は実機のスクリーンショット実測に基づく大きさで、画面下端に密着して配置される（縦向き）。横向きでは盤面の高さが55dvhに収まる。
- R3: 主要コンテンツと操作はなるべく一画面に収まり、スクロールは最小限。文字の切れ・はみ出しがない（375px幅を含む）。
- R4: 説明文・免責的な文章は画面の下部に置き、上部は本題のコンテンツと操作を優先する。ヘッダーは最小限の高さ。
- R5: 画面の拡大ができない（viewport設定に加え、ピンチ・ダブルタップ・Ctrl+ホイールのズーム操作を抑止）。

### 盤面とドロップ
- R6: 盤面サイズは 5×4 / 6×5 / 7×6 の3種を切り替えられる。最大コンボ数の目安は各 6 / 10 / 14。
- R7: ドロップは基本6色（火・水・木・光・闇・回復）に毒・猛毒・お邪魔・爆弾を加えた全種が扱える。
- R8: シャッフルで生成した盤面は初期状態でマッチ（3個つながり）が一切成立していない。

### 操作感（本家再現の中核）
- R9: ドロップを掴んで一筆書きで動かす方式。掴んだドロップは指（ポインタ）に正確に追随し、通過したマスのドロップと1マスずつ入れ替わる。速いフリックでもマスを飛ばさない（経路補間）。斜め移動も本家同様に扱えること。
- R10: 操作時間は 1.0〜200.0 秒を 0.1 秒刻みで設定でき、デフォルト6.0秒。移動開始でカウントダウンが始まり、時間切れでその場で手を離した扱いになる。残り時間の表示・バーが実時間と一致する（解決処理の前後で表示が巻き戻ったりしない）。
- R11: 2本目の指や別のポインタが進行中のドラッグを横取りしない。ドラッグの中断（pointercancel等）で盤面が壊れない・固まらない。
- R12: テープのマスはドロップの通過を遮る。
- R13: ドロップの移動・落下は滑らかにアニメーションする（瞬間移動やガタつきがない）。補充ドロップは盤面上部から列ごとに積み重なって落ちてくる。

### コンボと落下
- R14: 指を離した時点で、まず未マッチの爆弾が爆発し、その後にコンボが1つずつ順に処理される（爆弾→コンボの順序）。
- R15: 落下（重力）の後、既存ドロップ同士でそろったものはコンボとして数える（いわゆる「落とし」は成立する）。
- R16: 補充の方式は2モードある。「落ちコンなし」（基本設定、本家の落ちコンなしスキルと同じ仕様）では、消えて空いたマスはターンの間は空白のままで、新しいドロップは一切落ちてこない（既存ドロップの落下と「落とし」だけが起きる）。盤面のコンボがすべて終わった時点で空きマスが補充され、その補充ではコンボが成立しない。「落ちコンあり」では消えるたびに補充が自然に行われ、落ちコンが発生しうる。
- R17: コンボ処理のテンポは実機に近い速さで、1コンボずつの表示（ポップ）が追えること。

### ギミック（数値・仕様は本家準拠）
- R18: 毒：つながったグループごとに (個数+1)×5% の被ダメージ（最大HP比）。猛毒は (個数+1)×12.5%。
- R19: 爆弾：指を離した時点でつながっていない爆弾が爆発し、1個につき20%の被ダメージ、その爆弾の縦列と横行すべてを破壊する（ロックされたドロップも破壊される）。3個以上つながった爆弾は安全に消える。
- R20: トゲ：トゲ付きドロップが移動でずれたマス数×4% の被ダメージ（掴んでいるドロップ自体は対象外）。
- R21: ルーレット：色の変化順は 火→水→木→光→闇→回復。速度は 2秒/1秒/0.5秒 の3種＋個別指定。色の絞り込みプリセット（2色のみ等）とカスタム指定ができる。盤面上の全ルーレットマスは**同じタイミングで一斉に**色が変わる（単一の時計）。掴んでいるドロップとロックされたドロップは変化が止まる。それ以外のマスはドラッグ中も変化し続ける。マスから出たドロップは表示していた色のまま確定する。
- R22: 雲：そのマスのドロップが完全に見えなくなる（透けて見えない）。掴んだ場合は見える。
- R23: 暗闇・超暗闇：ドロップが見えなくなる。超暗闇は残りターン数が表示され、ターン経過で減る。
- R24: ロック：通常の3個消しでは消えず、L字消しで盤面全体のロックが外れる（簡略ルール、R-意図的仕様2）。強化・弱化（ドロップ強化/弱化表示）、消せない状態も付け外しできる。
- R25: 被ダメージは毒・猛毒・爆弾・トゲのみが対象で、合計がそのターンの被ダメ%として表示され、次のターンにリセットされる。

### 目覚め（落ちてくるドロップの偏り）
- R26: 目覚めプリセット：なし（6色均等）、毒・お邪魔・トゲ（毒20%・お邪魔20%・基本色各10%・トゲ修飾5%）、属性「多め」（対象属性が約3/8、他は均等）、「2属性のみ」（火水・水木・木火・光闇、各50%）。シャッフル生成にも同じ偏りが適用される。
- R27: 目覚めと落ちコンの有無は独立に組み合わせられる。「落ちコンなし＋2属性のみ」のような組み合わせでも、ターン終了時の補充でコンボが成立しない保証が破綻しない（どうしても避けられない場合のフォールバック挙動が破壊的でないこと）。

### 編集・リセット
- R28: 編集モードには「ドロップ」「状態」「一括」の3タブがある。「状態」タブにはドロップの状態パレットとマスのギミックパレットの両方があり、「全状態クリア」ボタンで盤面全部の状態とマスギミックを一括で消せる（ドロップの種類は変えない）。
- R29: 一括タブで全マス一色化と多色陣（ランダム配置、初期マッチなし）ができる。
- R30: 「設定リセット」は全設定（盤面サイズ・操作時間・落ちコン・目覚め・ギミック類）を初期状態に戻し、プレイ画面に戻る。
- R31: 「状態リセット」は盤面を一切変えずに、ターン・コンボ・最大コンボ・被ダメ・直近結果・アンドゥ履歴をリセットする。
- R32: 「元に戻す（アンドゥ）」は1手前の状態（盤面・位置ギミック・ターン・被ダメ・最大コンボ・直近結果の表示まで）を完全に復元する。編集・サイズ変更・シャッフル・読み込み等の後はアンドゥできない（古い盤面への巻き戻り事故が起きない）。
- R33: 破損したデータや想定外の入力でも画面が真っ白にならない・例外で止まらない（データ検証が機能する）。

## 監査の観点（すべて実施すること）

- A. 仕様照合：要件リストR1〜R33の各項目をコードと突き合わせ、満たしていないものを列挙。
- B. 実機再現度：数値（R18〜R20）、処理順序（R14）、タイミング（R17、R21）、操作感（R9）を本家仕様と照合。本家仕様の参照元を明示すること。
- C. 不変条件：どの操作順序でも「盤面に空きマスが残らない」「未定義の状態にならない」「コンボ解決が必ず終了する（無限ループしない）」が保たれるか。
- D. 統計検証：R26の分布がコード上の重みから理論的に正しいか（実測手順の提案でも可）。落ちコンなしモードで補充直後にマッチが成立しないことの検証方法も示すこと。
- E. 入力堅牢性：連打、解決処理中の操作、マルチタッチ、ドラッグ中断、タブ切り替え中の操作、サイズ変更直後の操作などで状態が壊れないか。
- F. レイアウト：375×667 / 375×760 / 390×844 / 430×932 / 横向き / デスクトップ幅での表示（文字切れ、操作要素のはみ出し、スクロール前提になっていないか）。
- G. 性能：7×6盤面での連続操作・アニメーションが破綻しないか。
