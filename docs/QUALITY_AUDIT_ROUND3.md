# 品質保証監査レポート（第3回：ChatGPT相互監査の照合）

- 対象: sylpica/Puzzle-Dragons（パズドラ練習アプリ、index.html 単一ファイル）
- 実施日: 2026-11-05
- 起点: main `85b22d1`（第2回監査完了・公開反映済み）
- 方式: 第2回で策定したフェイリス式監査プロンプト（docs/AUDIT_PROMPT_FEIRIS.md）を ChatGPT（chatgpt.com、思考量「高」）の新規チャットへ投稿し、返ってきた独立監査の全指摘を、リポジトリ実物・一次情報・実走テストで1件ずつ照合した。ChatGPT の回答は鵜呑みにしていない。
- ChatGPT 側の動き: 監査回答に加え、修正案を Draft PR #1（ブランチ `audit/independent-spec-invariants-20261105`、docs/QUALITY_AUDIT_INDEPENDENT.md と tests/spec-regression.mjs を含む）として作成していた。本レポートの照合を経て、採用分は検証済みの自前実装として main へ反映し、PR #1 はマージせずクローズした（ブランチは保持）。

## 照合結果（ChatGPT の指摘 R-01〜R-08）

| ID | 指摘 | 照合結果 | 対応 |
|---|---|---|---|
| R-01 | ルーレットがドロップ保持中は盤面全体で停止する。本家では保持中・ロック中のドロップだけが止まる | コードで実在を確認。攻略情報源（AppMedia「ルーレットの対策」、海外攻略ガイド）でも「止まるのは掴んでいるドロップとロック中のみ、他は操作中も変化」で一致 | **採用・修正**: tick の停止条件を「解決中／保持中のマス／ロックされたドロップのマス」に限定。実測 T1（保持中に他マスは進行、保持マスとロックマスは停止） |
| R-02 | 孤立爆弾の爆発が、3個以上つながった別の爆弾まで破壊する | コードで実在を確認。非公式wiki FAQ「3個以上つながった爆弾は孤立爆弾の爆発に巻き込まれずコンボに残る」が根拠（単一の攻略情報源のため、その旨を明記） | **採用・修正**: 指を離した時点でマッチしていた爆弾マスを破壊対象から保護。実測 T2（孤立爆弾1個爆発で被ダメ20%、接続爆弾は3個コンボ消去、1コンボ） |
| R-03 | 同時成立コンボはまとめて判定すべきで、グループごとに補充するのは本家と異なる | 本家の挙動としては正しいが、ユーザーの明示指示「1コンボずつ発生します」と競合する | **不採用**（ユーザー仕様を優先）。PR の該当変更（pendingGravity 構造を含む）は取り込まない |
| R-04 | 読込検証が甘く、重複UID・未知フィールド・範囲外のルーレット位相を通す | コードで実在を確認（重複UIDは描画ノード衝突の実害あり） | **採用・修正**: sanitizeData を厳格検証へ置換（キー許可リスト、UID重複拒否、型・範囲チェック、位相は色数未満のみ許可）。盤面コード入力に長さ上限100,000文字を追加。実測 T4（3種の不正を拒否、正常盤面は読込可）。保存・書き出しの往復同一性は feiris2 で回帰グリーン |
| R-05 | アンドゥで最大コンボと直近ターン結果が復元されない | スナップショットに該当項目が無いことを静的確認 | **採用・修正**: スナップショットに最大コンボと表示一式（コンボ表示・直近結果・ダメージログ）を追加し復元。実測 T3 |
| R-06 | 一部の編集後にアンドゥ用スナップショットが残る | paint() が無効化していないことを静的確認 | **採用・修正**: paint で無効化。あわせてモード切替時は未完了ドラッグを取り消して無効化、ダメージボタンでも無効化。実測 T5（モード切替後のアンドゥ不可） |
| R-07 | タイムアウト直後にタイマー表示が設定時間へ戻る | コードで実在を確認 | **採用・修正**: stopTimer(resetDisplay) 化し、解決中は 0.0 表示を維持、終了後に復元 |
| R-08 | 本家の基本操作時間は現行6秒（アプリ初期値5秒と不一致） | **公式で確認**: ガンホー公式 Ver.21.7 アップデート情報で 2024-08-30 に基本操作時間が5秒から6秒へ変更（北米公式にも同旨の記載） | **値を変更せず差異を明記**: 初期値5秒はユーザーの明示仕様のため保持し、フッターの仕様メモに「本家は6秒、本家準拠なら6.0秒に設定」と追記 |

付随採用: 補充マッチ予測（refillWouldMatch）の横方向も effType で判定するよう統一（第1回 F-07 の横方向版）。

ChatGPT の統計検証（補充44,400ドロップ、目覚めONで毒19.72%／お邪魔19.28%／トゲ5.01%）は、第2回の自前測定（毒・お邪魔 約20%、トゲ 約5%）と整合した。

## 追記（2026-11-05、監査後）

R-08 の扱いは本レポート作成直後にユーザーの指示で変更された。初期値は「ユーザー仕様として5秒を保持」から、本家の現行仕様に合わせた **6.0秒** へ変更済み（入力欄・スライダー・残り時間表示・設定リセットの既定値を含む）。フッターの仕様メモも「初期値は本家の基本操作時間に合わせた6.0秒です」へ更新した。

## 訂正記録

第1フェーズの学習レポートで「基本操作時間は5秒（Ver.13.0以降）」とした記述は、Ver.21.7（2024-08-30）の変更により失効していた。現在の本家の基本操作時間は6秒が正しい。アプリの初期値5秒はユーザー仕様として意図的に維持する。
