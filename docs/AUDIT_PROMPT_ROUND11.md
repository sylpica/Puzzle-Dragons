# パズル練習アプリ 最終監査プロンプト（ラウンド11：修正再検証と最終収束確認）

あなたは熟練のQAエンジニアです。添付の単一HTMLファイル（パズドラ風パズル練習アプリ）を、実際にブラウザで動かして監査してください。静的コードレビューだけでなく、実操作・実測による判定を必須とします。本ラウンドは「前ラウンド指摘の修正が正しく入り、副作用がないか」と「機能どうしの組み合わせで初めて出る不具合がないか」を確かめる最終確認です。

## 対象アプリの仕様（意図どおりの挙動 — 指摘してはいけないもの）

- 盤面 5×4 / 6×5 / 7×6、初期状態はシャッフル直後の盤面でギミックなし。操作時間の初期値は 6.0秒（1.0〜200.0、0.1刻み）。
- パーティ・敵・HPゲージ・勝敗判定は未実装が仕様。ダメージ表示は最大HP比%のみ（毒：つながり1組ごとに（個数+1)×5%、猛毒（個数+1)×12.5%、爆弾は未マッチで離すと先に爆発し1個20%＋行列破壊、棘は移動でずれたマス数×4%）。
- 爆弾の保護：3個以上つながった爆弾は他の爆弾の爆発で**破壊されません**。ただし解決の順序は「未マッチ爆弾の爆発→落下→コンボ判定」で本家と同じであり、落下で繋がりが崩れた場合はコンボになりません（保護は破壊されないことであって、コンボの保証ではありません）。
- コンボは本家同様1コンボずつ順に発生します（一括判定ではありません）。
- 落ちコンなし：消去したマスはターン終了まで空白のまま（既存ドロップの落下のみでコンボ可）、補充は全コンボ終了後に1回のみ、その補充ではコンボしません。落ちコンあり：消去のたびに落下＋補充。
- ルーレット：色の順序は火→水→木→光→闇→回復。全マス同一のグローバル時計で同時に変化し、掴んでいるマスとロック中のドロップは停止。解決中は位相を固定。間隔プリセットは 2秒/1秒/0.5秒、色集合はカスタム可（毒・お邪魔も含められる）。特殊ドロップがルーレットマスに入ると火に変換（ロック中を除く）。**カスタム色は最低1色**（UIで最後の1色は外せない、保存値に有効な色がなければ初期6色）。
- ロック解除はL字マッチ時のみ（簡易仕様として明記済み。L字の角マスを含むこと）。
- 超暗闇：残りターン数のカウンタつきで落ちてきます（目覚めトグル時、約3割のドロップに残り1ターン）。ターン開始時に盤面にあったドロップだけが、そのターンの解決終了時にカウントダウンします（解決中に生まれたドロップは次のターンから）。
- 目覚め「のみ」は 2〜4色のカスタム色集合で、そのとき落下プールは集合の色のみ（特殊ドロップ目覚めと併用しても混ざりません。棘・超暗闇は修飾として付けます）。目覚め「割合アップ」の実効比率は約33%（マッチ回避リロールの結果として仕様メモに明記済み）。
- 消せない属性は属性単位の指定で、盤面リセットやサイズ変更でも保持され、全リセットと全状態クリアでのみ解除されます。
- アンドゥ：ドラッグ開始時点ではなく、最初に実際に交換した時点で確定します。無操作のタップ、編集で実際に変化がなかった操作（同種・無修飾ドロップの再配置、消すもののない全状態クリア、無変化のペイント等）では履歴は消えません。実変更のある編集・一括操作・サイズ変更・シャッフルでは履歴は破棄されます。
- 設定のみが端末に保存されます（操作時間・落ちコン・目覚め・のみ色集合・特殊目覚め・消せない属性・盤面サイズ・ルーレットのプリセット/色/間隔）。**盤面そのものは保存されません**。保存値の検証：操作時間は 1.0〜200.0 の範囲外なら初期値6.0に戻ります（境界値に丸めません）。ルーレット色は有効な色だけが残り（重複除去）、1色も残らなければ初期6色。型違い・壊れたJSON・未知の値は項目ごとに初期値へ。
- 全リセットには確認ダイアログがあります。記録リセット・盤面リセットに確認はありません。
- ポインターキャンセル（OS割り込み）では手は無効になり、操作前の盤面に復帰してターンは進みません。
- 「元に戻す」ボタンは、戻せる履歴がない間は無効表示です。
- ルーレットマスが1つもないときは、ルーレット時計による待機中の再描画は行われません。
- 編集モードのタブと選択ツールは、モードを往復しても保持されます。
- 非収束フェイルセーフ：落ちコンありで全ルーレットマスの同一マッチが3回連続したら解決を打ち切りターン終了処理へ移ります（上限99コンボ）。これは無限ループ回避のための仕様です。
- 盤面表示：縦向きは画面幅いっぱい（最大480px）、横向きは縮小して中央に置かれます。ページズームは全面禁止が仕様。

## 監査項目

### Z1. ラウンド10修正の再検証（本ラウンドで直したもの）
1. 保存値の操作時間：999、-50、0.9、200.1 → 初期値6.0に戻ること。1、6.0、12.5、200 → そのまま復元されること。ユーザー入力欄からの 0 や 201 は従来どおり 1.0／200.0 に丸められること（保存の扱いと入力の扱いは別です）。
2. 保存値のルーレット色：["nonesuch"] → 初期6色になること。["fire","nonesuch","fire"] → 有効な色だけ（fire）で復元され、0色にならないこと。UIで色を1色だけ残した状態から最後の1色を外そうとしても外れないこと。0色の状態でルーレットを置いても未定義の種類のドロップが生まれないこと。
3. 無変化の編集：修飾のないマスへの同種ドロップ再配置、消すもののない全状態クリア、で履歴が保持されること。修飾のあるマスへの同種再配置（修飾が消える＝実変更）、実ギミックのある全状態クリア、では履歴が破棄されること。
4. 爆弾の意味論：ラウンド10と同じ盤面（上段に爆弾3個＋孤立爆弾1個、落ちコンなし）で、被ダメ20%・0コンボ・保護された3個がドロップとして盤面に残ること。逆に、孤立爆弾の爆発で分離しない配置（例：最下段に横3個＋その真上に孤立爆弾なし）では爆弾コンボが通常どおり成立すること。爆発で下の支えが消えても3個の接続が保たれる配置でもコンボが成立すること。

### Z2. 組み合わせマトリクス（新規の探索軸）
次の軸の組み合わせを系統的に変えながら、各条件で解決を50回以上実行し、不変条件（例外0、盤面に空マス・未定義種類が残らない、ターンとコンボ表示の整合、ダメージ表示が 0〜理論上限の範囲）を検証してください。
- 軸：落ちコン あり/なし × ルーレット盤面 あり/なし × 消せない属性 あり/なし × 特殊目覚め（お邪魔・毒・猛毒・棘・超暗闇の全ON）× 目覚め（なし/割合アップ/のみ）
- 特に、フェイルセーフ（同一ルーレットマッチ3回連続の打ち切り）が通常の解決を誤って打ち切らないこと、全ルーレットでない盤面で99コンボに到達する前に正しく自然終了することを確認してください。

### Z3. 保存のファズ
- 保存キーに、ランダムなJSON変異（型違い、欠けた項目、余分な項目、極端な数値、null、配列と文字列の入れ替えなど）を200パターン以上流し込み、各回でアプリが例外なく起動し、全設定が「保存値どおり」か「項目ごとの初期値」のどちらかになっていること（中間の壊れた値にならないこと）を確認してください。

### Z4. 仕様メモ（フッター）全文章の最終突合
- フッターの仕様メモ全文を文章単位で列挙し、各文が実測と一致するか検証してください。特に爆弾の保護に関する文（ラウンド10で改訂）と、設定保存に関する文に注目してください。

### Z5. 収束判定
- ラウンド1〜10で修正された全領域（ドラッグとポインター、爆弾、毒・猛毒・棘、ルーレット全般、落としと補充、アンドゥ、編集、リセット群、レイアウト、保存、表示）から回帰がないか最終確認し、「新規指摘ゼロ（収束）」か「残存指摘あり」かを明言してください。

## 出力形式（厳守）
