## 意図的な仕様（欠陥として扱わないこと）
- コンボは1コンボずつ順に発生する（同時判定しない）。演出は1コンボあたり約250ms。
- 落ちコンなしが基本: 消去で空いたマスはターン中は空白のまま、新ドロップは落ちてこない。既存ドロップの落としによるコンボは成立する。盤面のコンボ終了時に空マスへ補充し、その補充ではコンボは成立しない。
- 操作時間の初期値は6.0秒（本家の現行仕様）。
- ルーレットは全マス共通のグローバルクロックで同期し、操作中も回り続ける（掴んでいるマスとロックされたドロップは凍結）。解決中は位相をラッチする。表示の更新は約100ms間隔のポーリング追従のため、位相切替直後に最大で約100msの表示遅延がありうるのは設計の範囲。全マスが同じルーレットの盤面ではシャッフル後もマッチが残りうる（仕様メモに明記済み）。
- ロック解除はL字消しの簡略ルール。3個以上繋がった爆弾は他の爆弾の爆発に巻き込まれない。
- 目覚め「多め」の出現率は実測約33%（公称3/8とは異なる）のが正常。
- 特殊目覚め: お邪魔・毒・猛毒は補充プールに重み付きで混ざる（単独ONで約25%）。ただし目覚め「のみ」選択中は混ざらない（「のみ」は絶対: 選んだ色のドロップだけが落ちる。トゲ・超暗闇は選んだ色のドロップに付く修飾なので「のみ」でも付く）。トゲは補充ドロップの15%に付く。超暗闇は補充ドロップの約30%に**残り1ターン**で付き、**落ちてきたターンの解決では減らず、次のターンの解決の終わりに0になる**（ターン開始時に盤面にあったドロップだけが解決末にカウント減少する仕様）。落下率は本家非公表のため割合はアプリの練習用設定。
- 「のみ」では選んだ2〜4色以外のドロップは落ちてこない（落ちコンなし補充・シャッフル・盤面リセットでも純度が保たれるのが仕様）。
- 消せないは属性単位で選ぶ仕様。属性判定は現在の実効タイプ（ルーレット表示色を含む）に対して行う。消せない属性の選択は、盤面リセットや盤面サイズ変更では保持され、全リセットと全状態クリアでのみ初期化される。
- ドラッグ中、掴んだドロップは指が盤面の外に出ても盤面の内側に収まるようクランプされる（入れ替え判定はマス単位）。
- 盤面の表示: 縦向きでは表示幅いっぱい（最大480px）で下端に接し、横向きでは高さに合わせて縮小して中央に表示する。
- 保存機能は廃止済み（存在しないのが正常）。ページズームは全面禁止が仕様。
- パーティ・敵・HPゲージ・勝敗判定は未実装が仕様（ダメージは最大HP比%表示のみ）。

## 検証項目

### X1 ラウンド8修正の再検証
- 超暗闇のライフサイクル: (a) 落ちコンなしのターン末補充で付いた超暗闇が、その解決の終わりに消えず残り1ターンのまま残ること。(b) 次のターンの解決の終わりに0になること。(c) 落ちコンありの連鎖補充で途中に付いた超暗闇も、その解決中は減らないこと。(d) 爆弾で破壊されたマスへの補充など、他の経路の補充でも同じであること。(e) 編集で置いた超暗闇（カウント3など）は毎ターン1ずつ減ること。
