# Puzzle-Dragons

パズドラ（パズル＆ドラゴンズ）のパズル練習アプリです。開いてすぐにパズル画面で、自由練習が主役です。

公開ページ: https://sylpica.github.io/Puzzle-Dragons/

## できること

- 盤面サイズ 5×4 / 6×5 / 7×6 をその場で切替。本家同様、盤面は画面幅いっぱい・1マス正方形・下端接しレイアウト
- ドロップを掴んで一筆書きで入れ替える本家方式の操作。操作時間は基本5.0秒、画面上で1.0〜200.0秒まで0.1秒刻みで変更可能
- 落ちコンは常になし（補充ドロップではコンボが成立しないよう調整。自分の消去による落としは成立）
- ギミック全部入り
  - ドロップ: 火・水・木・光・闇・回復・毒・猛毒・お邪魔・爆弾
  - 状態: 強化＋・弱化・ロック・トゲ・暗闇・超暗闇（ターン表示）・消せない。L字消しでロック解除
  - マス: 雲（ターン表示）・テープ（操作不可）・ルーレット
  - ルーレットは低速2秒／通常1秒／高速0.5秒に加え、水・回復のみ等の指定色ルーレット、カスタム（色の組み合わせと間隔を自由指定）に対応
- 編集モードで任意盤面を作成（タップ・なぞり配置）。盤面の保存（ブラウザ内）とコード書き出し／読み込み
- 一括盤面変更: 全マスを1色に、選んだ色の組み合わせで陣（2色陣など）をランダム生成
- シャッフル盤面（毒・お邪魔・トゲが落ちる「目覚め」再現オプション付き）
- 体力ゲージの代わりに、受けたダメージを最大HPに対する割合（%）で内訳表示
  - 毒: 1コンボにつき（繋げた個数＋1）×5% ／ 猛毒: （個数＋1）×12.5%
  - 爆弾: 残すと1個20%、縦横1列を破壊（指を離した時点で繋がっていなければ爆発）
  - トゲ: トゲ付きドロップを1マスずらすごとに4%
